# Results

This directory contains selected, human-readable results intended for inspection and publication-oriented presentation.

The complete computational outputs are stored under:

`analysis/`

The analysis scripts are stored under:

`scripts/`

## Main Result Categories

The benchmark produces results related to:

- early-warning precedence;
- warning horizons;
- robustness and sensitivity;
- cross-expression generalization;
- cross-identity generalization;
- representation-level validation;
- final synthesis.

## Reproducibility

Results should be interpreted together with the corresponding analysis script and stage-specific output directory.

The `analysis/` directory contains the complete machine-generated evidence used by the final synthesis.
